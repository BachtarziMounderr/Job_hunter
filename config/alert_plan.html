Configurer les alertes Algérie

Une configuration initiale ; la lecture quotidienne sera ensuite automatique.

  1. Ouvrir les recherches, vérifier le pays Algérie, puis activer les alertes quotidiennes par email.
  2. Dans Gmail, créer le libellé JobHunter/Alerts et un filtre qui y range les alertes des expéditeurs officiels.
  3. Connecter Gmail avec python scripts/setup_gmail.py --client private/google-client.json.
  4. Le programme lit les alertes et envoie le bilan sur Telegram. Les extraits incomplets seront signalés « à vérifier ».
